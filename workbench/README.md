# Privacy Review Workbench

Optional local demo app for ContextSafe-HSD.

```text
workbench/backend/    FastAPI wrapper
workbench/frontend/   React/Vite UI
```

## Run

```bash
python -m pip install -e '.[workbench]'
python launch.py --install
```

Open `http://127.0.0.1:5173`.

## Notes

- Exact CSV export replaces the selected text column in place.
- Local LLM review is sidecar-only and receives cleaned text.
- Platform insight uses explicit CSV labels or local LLM sidecar labels only.
- Citizen validation restatements are generated by an explicit local LLM pass
  over protected text only; the dashboard does not use deterministic
  restatement as review evidence.
- Optional semantic comparison uses a local embedding model to score original
  text vs. the citizen restatement while retaining only the score/status.
- Cached processed CSV results and review annotations live under
  `workbench/.cache/`; the portal can list and reload saved processed results
  without rerunning the local LLM or embedding stages.
- Use synthetic or consented text for demos.
